## 选一个稳定的文件名

在仓库的 `src/content/blog/` 下新增文件，例如 `first-field-note.md`。文件名会成为文章地址的一部分。以后只修改标题时可以保留文件名，让过去分享的链接继续有效。

## 填写文章信息

复制同目录一篇笔记的文件头，替换标题、摘要、分类和日期。`date` 保存文章日期；`publishedAt` 保存精确发布时间，必须使用带时区的 ISO 8601 时间，例如 `2026-11-22T09:30:00+08:00`（中国标准时间）。首页和列表按 `publishedAt` 倒序排列；没有 `publishedAt` 的旧文章兼容使用 `date` 排序，并只显示日期。撰写期间可以加上 `draft: true`，构建时会隐藏草稿。摘要写清楚读者读完能完成什么，正文按实际操作顺序展开。

## 用预览确认结果

在新分支提交内容。运行 `npm ci`、`npm run build` 和 `npm run verify`，然后用 `npm run preview` 打开文章。检查手机宽度下的标题、正文和站内链接。准备发布时移除草稿标记。

## 核对线上版本

合并到生产分支后，在已连接的 Cloudflare Pages 项目里核对部署对应的提交号。部署成功后打开文章与博客列表，两处都应出现新标题。
